## 2. Apply for Services (`/services`)

### Layout & Blueprint
- Clean list of the 8 statutory university research services with eligibility tags and processing turnaround:
  1. Research Advisory Committee (RAC) / Three-Member Committee
  2. Title Change Application
  3. Research Centre Change
  4. Guide Change Request
  5. Scholar Leave Request
  6. Course Period Extension Request
  7. Condonation of Attendance Shortage
  8. Pre-Submission Application & Thesis Submission Clearance
- Each card has: Service title, brief statutory explanation, required document checklist, and action button `[Apply now]`.

---

## 3. Application Detail Screen (`/applications/:id`)

### Layout & Blueprint (Split View for Viewports >= 1024px)
- **Left Column (60%): Application Facts & Documents**
  - Application Metadata (Ref Number, Type, Submission Date, Applicant).
  - Form Fields (e.g. Existing Title vs Proposed Title, Justification).
  - Attached Evidences (downloadable links with file size and verified MIME badge).
  - Official Replies & Section Remarks (Orders generated by Staff, stamps).
- **Right Column (40%): Timeline & Actions**
  - Full `Timeline` component rendering the historical steps, current waiting officer, and future steps.
  - If status is `RETURNED`: Render `[Edit and resubmit]` button.
  - If status is `DRAFT` or `RETURNED`: Render `[Cancel application]` button.

---

## 4. Research Timeline Screen (`/timeline`)

### Layout & Blueprint
- Detailed chronological milestone tracker for the PhD lifecycle:
  1. Date of Provisional Registration
  2. Date of Research Commencement
  3. Course Work Examination Completion & Grade Sheet
  4. RAC Review #1 (6 Months) — Completed
  5. RAC Review #2 (12 Months) — Completed
  6. RAC Review #3 (18 Months) — Current / Scheduled
  7. Comprehensive Viva Voce / Confirmation
  8. Pre-Submission Seminar Presentation
  9. Final Thesis Submission Clearance
